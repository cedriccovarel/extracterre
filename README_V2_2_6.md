# ExtracTerre v2.2.6 — Analyse manuelle documentaire

## Parcours

1. Importer les documents dans les dropzones habituelles et lancer leur lecture.
2. Dans **Analyse du projet**, cliquer **Analyse manuelle**.
3. Choisir la pièce et la page/feuille à gauche.
4. Choisir le bâtiment à droite.
5. Choisir **Thermique**, **Carbone** ou **Enveloppe**.
6. Cliquer le bouton du champ à renseigner.
7. Surligner la valeur dans le PDF ou cliquer la cellule dans Excel.

La valeur est affectée immédiatement. Pour un champ numérique, ExtracTerre extrait le premier nombre exploitable de la sélection tout en conservant le texte source dans la provenance. Les valeurs manuelles restent prioritaires dans la consolidation.

Le lecteur PDF/OCR, la navigation Précédent/Suivant et le rendu Excel restent identiques à la fenêtre de correction.
