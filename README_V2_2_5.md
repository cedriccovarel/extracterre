# ExtracTerre v2.2.5 — aperçu Excel dans la fenêtre de correction

- Les fichiers `.xlsx` / `.xls` sont affichés comme une vraie grille de tableur dans la fenêtre de correction.
- Chaque feuille reste accessible depuis le sélecteur Feuille/Page et avec Précédent / Suivant.
- En-têtes de colonnes A, B, C… et numéros de lignes sont figés pendant le défilement.
- Un clic sur une cellule la sélectionne et recopie immédiatement son contenu dans « Valeur exacte ».
- Il reste possible de sélectionner seulement une partie du texte d’une cellule puis d’utiliser « Utiliser la sélection ».
- Les PDF conservent l’aperçu visuel + texte natif/OCR.
