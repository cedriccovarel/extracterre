# ExtracTerre v2.2.10 — Généralités dans l’analyse manuelle

Dans **Analyse du projet > Analyse manuelle**, la barre latérale comporte désormais quatre familles :

1. Généralités
2. Thermique
3. Carbone
4. Enveloppe

L’onglet Généralités regroupe les données des familles **Administration**, **Programme** et **Certification & exigences** du dictionnaire ExtracTerre.

Le fonctionnement reste identique : sélectionner le bâtiment, choisir le champ, puis soit surligner la valeur dans le PDF, cliquer une cellule Excel, soit saisir la valeur manuellement. Les sélections documentaires continuent d’alimenter l’apprentissage d’emplacement.
