# Bibliothèque isolants — v2026-09-07

La bibliothèque comprend 173 variantes produit / épaisseur / résistance thermique R.

- 150 variantes cœur : laine de verre, fibre de bois, PSE / polystyrène, biosourcés.
- 23 variantes complémentaires : PUR (SOPREMA TMS, Unilin Utherm Floor).

## Gammes principales

- Isover : GR 32, GR 30, Isoconfort 32, Isoconfort 35.
- URSA : Hometec 32 et alias proches.
- Isonat : Flex 55.
- STEICO : STEICOflex 036.
- PAVATEX / SOPREMA : PAVAFLEX CONFORT.
- Biofib : Trio, Chanvre.
- Le Relais Métisse : Métisse RT / Coton Pro P/R.
- Knauf : XTherm ITEx Sun+, NEXTherm ITEx, Therm Chape Th 38.
- SOPREMA : TMS.
- Unilin : Utherm Floor K.

## Règle de sélection

1. Valeur directe RSET si elle existe.
2. Autre valeur documentaire directe fiable.
3. Bibliothèque uniquement si la gamme produit et une épaisseur compatible sont identifiées.
4. Aucun R n'est inventé si l'épaisseur n'est pas identifiable.
5. Toute valeur issue de la bibliothèque porte une provenance et un commentaire.

Le fichier `data/insulation-library.json` expose le référentiel utilisé par le moteur.
