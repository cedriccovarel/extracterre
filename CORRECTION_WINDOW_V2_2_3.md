# ExtracTerre v2.2.3 — fenêtre de correction

La sélection surlignée dans la page PDF ou OCR alimente immédiatement le champ **Valeur exacte**. Le texte sélectionné est conservé tel quel dans le champ pour que l’utilisateur voie exactement ce qui a été choisi. Pour un champ métier numérique, la conversion en nombre est réalisée seulement au moment de la validation.

La fenêtre est organisée en deux zones : aperçu PDF à gauche et correction à droite. Le panneau de droite conserve le champ, le bâtiment, la valeur/source actuelles, le contexte, la valeur exacte, le motif, le commentaire et l’option d’application immédiate.
